## How To Use This Folder

This folder contains deeper notes by phase.

Use it like this:

- use `docs/02-progress-tracking/current-status.md` for the short current snapshot
- use `docs/02-progress-tracking/progress-tracker.md` for the active backlog
- use this folder for deeper historical context, detailed task lists, or older phase writeups

In other words:

- current execution lives in `02-progress-tracking`
- detailed reference material lives here
